# 넣을 내용
프로젝트: 잔여배차 처리 자동화 (딜리버스, 물류 운영 기획)
내 역할: 기획

1. Dispatch v2.0 (잔여배차 개편), 2026-07-01 배포
   - 잔여배차 1곳을 채우는 커뮤니케이션에 건당 약 20분이 걸리던 걸 시스템 자동 처리로 바꿈
   - 토요일 평균 40건을 자동 처리, 건당 10분 절약 → 토요일 400분 절감 (건당 20분 → 10분)

2. 운송사 수기공고 직접 등록 + 수기 공고 개선
   - 운송사가 잔여배차 공고를 직접 올리게 해서 운영팀 중계를 없앰
   - 나머지 60건도 건당 5분 이상 추가 절약 → 토요일 300분 이상 절감 (건당 10분 → 5분 이내)

최종 성과: 건당 20분 → 5분 이내 (75% 단축), 토요일 기준 약 700분(11시간 40분) 절감

보조 근거 (DB 실측): Dispatch v2.0 배포 후 토요일 14시대 배차의 50% 확정 도달 시각이 평균 10분, 80% 도달 시각이 평균 13분 빨라짐.

# 작성 규칙
- 위 숫자만 쓰고, 새로운 숫자나 성과를 만들어 넣지 마.
- "문제 → 한 일 → 결과(수치)" 순서로 2~4줄 bullet로 써줘.
- 첫 줄에 최종 성과(20분 → 5분, 75% 단축)가 보이게 해줘.
- 동사는 내가 한 일 기준으로 (기획, 설계, 도입 등). 개발은 내가 한 게 아니니 "개발했다"고 쓰지 마.
- 두 프로젝트를 한 항목으로 묶어도 되고, 나눠도 돼. 이력서 전체 분량 보고 판단해서 제안해줘.
- 수기공고 프로젝트 배포 시점은 모르니 비워두거나 나한테 물어봐.
